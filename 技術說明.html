Content Script
CrossRef
主要書目來源。提供作者、篇名、期刊、卷期頁、DOI、ISSN、出版商、issn-type 等核心欄位。
OpenAlex
補強收錄資料庫（Scopus / WoS）、期刊出版國、作者機構國碼、開放取用 URL、研究主題。
ORCID
查詢作者系所（Employment）。在 OpenAlex 回傳後立即並行查詢，不額外等待。
Unpaywall
提供開放取用 PDF / 落地頁網址，作為 _oa_url 欄位及無摘要時的補強路徑。
Semantic Scholar
摘要第三道備援（CrossRef 及 OpenAlex 皆無摘要時使用）。
TSSCI / THCI 靜態清單
內建台灣期刊收錄清單，以 ISSN 直接比對，無需外部查詢，涵蓋 TSSCI、THCI、THCI Core。

▸ 各類型共用欄位
論著類別 publ_tpe CrossRef type 依序比對規則：學位論文→10、conference→04、proceedings→04、journal-article→03、book-chapter→02、book→01。無法判斷時預設 03。 高
研究領域 field_cod AI 推斷 LLM 依篇名、摘要、OpenAlex research-topic 判斷，對應政大 50 餘個領域代碼。資工（EA）與社科（HE 等）有明確規則防止誤判。 中
篇名 title1 CrossRef CrossRef title[0]。機構典藏頁面擷取時取 <h1> 或 <meta> 標籤。 高
出版年月 publ_dt CrossRef 優先取 published-print，其次 published-online，再次 issued。格式轉為 yyyymm，僅有年份時補 01。 高
作者姓名 sta_chi CrossRef CrossRef author[i].given + family。若資料只有英文姓名，直接填英文（禁止從拼音推測中文字）。多位作者透過 DOM 解析直接取得，不經 AI。 高
作者系所 sta_ut_nam CrossRef / OpenAlex / ORCID 判斷順序：① ORCID Employment（最精確，包含系所名稱）→ ② CrossRef affiliation（取最小系所單位，如 "Dept. of CS" → "資科系"）→ ③ OpenAlex institution → ④ 無資料時留空。
純學校名稱（如 "National Chengchi University"）一律填空字串，不翻譯填入。
 中高
通訊作者 ca_sts CrossRef CrossRef author[i].corresponding == true → 填 "1"，否則 "0"。 高
跨國合作 trsnat OpenAlex 從 OpenAlex authorships 取各作者機構國碼陣列（_author_countries）：全為 TW → "0"；含 CN/HK/MO 且無其他外國 → "2"；含其他非 TW 國碼 → "1"。
OpenAlex 無資料時退回 AI 依 affiliation 文字推斷。
 中高
關鍵字 kw1–kw5 CrossRef / OpenAlex 優先取 CrossRef keyword，無則取 OpenAlex keywords，最多取前 5 個。 高
同儕審查 chk_tag — 書目資料中無此資訊，一律留空，由行政人員手動勾選。 手動
學校名義論著 sch_publ_tpe — 預設填 "Y"。多數情況正確，如教師以外校機構為通訊地址，需手動改為 "N"。 預設Y
DOI doi CrossRef CrossRef DOI 號碼本身，不含前綴 https://doi.org/。 高
開放取用連結 _oa_url Unpaywall / OpenAlex Unpaywall best_oa_location.url_for_pdf 或 url，次則 OpenAlex oa_url。 中高
▸ 期刊論文（publ_tpe = 03）專用欄位
刊登狀態 acc_flg CrossRef 機械性判斷：JSON 中 volume、issue、page 三個 key 同時存在且非空 → "0"（已刊登）；任一缺少 → "1"（未刊登 / Online First）。日期欄位對此判斷無影響。 高
期刊名稱 jnl_nam CrossRef CrossRef container-title[0]。 高
卷 / 期 / 頁次 vol / no / pp CrossRef CrossRef volume / issue / page。Online First 文章無 issue 時 no 留空。 高
收錄資料庫 citelist OpenAlex / TSSCI清單 / DBLP 程式預先判斷並以 _known_dbs 傳入，AI 直接採用：
• OpenAlex indexed_in：scopus→r、web_of_science→依主題域判斷 SSCI(b)/SCIE(c)/AHCI(a)
• TSSCI 靜態清單（ISSN 比對）→ e；THCI→n；THCI Core→n+q
• DBLP 查詢命中→j；出版商含 IEEE→k；ACM→i
WoS 子資料庫（SSCI/SCIE/AHCI）以 OpenAlex 主題域推導，標記「請確認」，由使用者驗證。
 中高
期刊出版國 nat_cod / nat_tpe OpenAlex 判斷順序：① OpenAlex primary_location.source.country_code（兩位 ISO 碼→三位，如 NL→NLD）→ ② CrossRef publisher-location（城市推國家）→ ③ 出版商名稱推斷（Elsevier→NLD 等）。nat_tpe 由 nat_cod==TWN 決定。 中高
論文性質 pertpe_cod CrossRef CrossRef type subtype：article→1、review→2、letter→3、note→4。 中高
出版形式 publ_type CrossRef CrossRef issn-type 陣列：print + electronic 皆有→"2"；只有 electronic→"1"；只有 print→"0"；無 issn-type→預設 "2"。 中高
文章網址 url_addr CrossRef / BibTeX 優先順序：① 輸入中的 URL 欄位（DOI 路徑為 https://doi.org/{DOI}，BibTeX 匯入時為文章原始連結）→ ② OpenAlex _journal_url（期刊首頁，備援）→ ③ 留空。 高
▸ 書籍 / 專書篇章（publ_tpe = 01 / 02）專用欄位
書名 / 出版社 / 出版地 set_title / publ_nam / publ_pls CrossRef / ISBN查詢 CrossRef container-title / publisher / publisher-location；ISBN 查詢走 Google Books 與 Open Library 補強。 中高
ISBN isbn_num CrossRef / NCL CrossRef ISBN[0]；無時查 National Central Library ISBN API 補強。 中高
▸ 會議論文（publ_tpe = 04）專用欄位
會議名稱 / 日期 / 地點 conf_nam / conf_dt / conf_pls CrossRef CrossRef event 物件（_conf_nam / _conf_dt / _conf_city / _conf_country）由程式預先格式化，AI 直接採用，不自行推斷。 高
國際研討會 intl_conf AI 推斷 會議名稱含 International / IEEE / ACM / Global / World 且舉辦地非台灣，或作者來自多國機構 → "1"（是）；否則 "0"。 中高
欄位隔離原則　publ_tpe 非 "03" 時，期刊專用欄位（jnl_nam、vol、no、nat_tpe、nat_cod、citelist、url_addr 等）一律填空字串，絕不填入會議名稱或其他非期刊資訊。同理，publ_tpe 非 "04" 時，會議欄位全部清空。此機制以硬性規則實作於 AI prompt，不依賴 AI 自行判斷。
書目輸入模式與資料路徑
輸入模式觸發方式主要資料路徑
DOI / PMID / arXiv / ISBN 使用者輸入識別碼 CrossRef（或 PubMed / arXiv API）查詢 → 並行補強 OpenAlex、ORCID、Unpaywall、DBLP → AI 映射
學術頁面擷取 開啟論文頁面時自動偵測 Content Script 讀取頁面 meta tag（Highwire / DC / OpenGraph）或 DOM 結構（AH DSpace、政大論文典藏）→ 加入待處理佇列 → 與 DOI 模式合併補強
RIS / BibTeX / ENW 匯入 點選「匯入」上傳檔案 解析檔案欄位 → 若有 DOI 自動補查 CrossRef → 合併（CrossRef 優先，檔案欄位填補缺口）→ AI 映射
純文字 / 引用格式貼上 使用者貼入文字框 ISSN / 期刊名萃取 → enrichPublicationText()：查 TSSCI 清單、OpenAlex Sources（Scopus / WoS）→ AI 映射
ORCID 被動追蹤 每日定時（Chrome Alarms） ORCID Works API → 比對已知著作清單 → 新著作通知 → 點選後進入 DOI 路徑或 ORCID 完整書目路徑
